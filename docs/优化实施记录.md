# UI 与功能优化实施记录

## 目标与约束

将个人文稿的写作、确认、渠道发布和结果追踪逐批优化。沿用 Spring MVC、Thymeleaf 与原生 CSS/JS，不引入第二套前端框架；所有后续项都要验证后才能标记完成。

维护者：修改对应功能的开发者；项目所有者确认产品规则。业务合同见[业务说明](FUNCTIONAL_SPEC.md)，架构见[技术设计](TECHNICAL_DEVELOPMENT.md)，运行与测试见[开发文档](开发文档.md)。

## 第一批：写作与查询可信度（2026-09-26）

### 已实现

- 编辑页默认折叠摘要、标签和关键词；辅助信息不再固定占据右侧 330px。
- 提供编辑、分栏、预览切换，记住非敏感显示偏好；小屏不堆叠两个正文区域，操作栏不固定遮挡输入。
- 创建页压缩重复标题，把标题和正文放在可选元数据之前；创建与人工发布表单增加离开提醒。
- 隐藏字段校验时自动展开信息区和对应语言页签。
- 英文生成结果进入自动保存；已有英文稿先确认替换，生成期间输入变化则不应用旧结果。
- 预览请求增加超时、序号与输入快照校验，旧回包不覆盖新内容。
- 人工发布明确区分步骤自动保存与正文提交，补齐输入标签关联。
- 覆盖矩阵和待发布使用数据库搜索与分页，不再局限最近 50 篇。待发布仅包含 `READY/APPROVED`；已发布文章从覆盖矩阵继续发布。
- 批次页明确其近期快照范围，修正成功计数说明，避免被误认为完整历史。

### 尚未实现的保存能力

新建文章和人工平台文本仍没有服务端自动草稿；离开提醒不是备份。主稿仍不支持跨标签页草稿并发版本号，关闭标签页后的应急恢复也不保证。没有新增数据库迁移或修改发布门禁。

### 验证

新增 `PersonalWorkspaceIntegrationTest` 场景覆盖超过 50 篇的搜索分页、待发布过滤、软删除和界面控件合同。

`scripts/test-workspace.cjs` 在隔离本地测试库验证创建 → 主稿 → 自动保存 → 本人确认 → 人工工作区；AI 返回值仅在浏览器中替换，不调用外部服务。还覆盖英文覆盖取消、生成期间编辑、预览乱序和五档宽度/明暗主题。执行方式与环境变量见开发文档。验收结果在实际执行后记录，不沿用 2026-09-22 的历史结果。

## 专项：深色主题配色（2026-09-26）

按用户后续要求单独优化深色颜色，不提前实施下表其他业务能力。

- 页面、侧栏、编辑区域、表头、代码块及浮层改用中性石墨灰层次；导航选中背景保持中性，绿色用于操作和强调。
- 调整正文、辅助文字、输入边界、焦点及成功/警告/错误颜色；监控主序列使用灰蓝，与成功绿色区分。
- 深色主按钮、危险按钮和 Webhook 次按钮的禁用态使用可读的中性文字与背景，而不是整块 `.45` 透明。
- 原有浅色主题变量逐项比对，值未改变。布局、业务流程、API、数据库、启动脚本和私有页面 `noindex,nofollow` 未变。
- 主题初始化与切换时从 CSS 读取页面背景色，同步浏览器 `theme-color`；没有增加依赖或在 JS 中重复维护颜色。
- 新增[主题色板](主题色板.md)，同步 README、技术设计、业务说明和文档索引。
