# 开发文档

基线：2026-09-26，`0.1.0-SNAPSHOT`。设计与模块边界见[详细技术设计](TECHNICAL_DEVELOPMENT.md)，业务规则见[业务说明](FUNCTIONAL_SPEC.md)，完整文档见[索引](README.md)。

## 环境与目录

- Java 17、仓库 Maven Wrapper；版本以根 `pom.xml` 和 `.mvn/wrapper/maven-wrapper.properties` 为准。
- 正式运行使用 PostgreSQL。本地可使用 Docker Compose 启动开发库，或传入已有的**开发/测试库**连接；不要连接生产库。
- `scripts/dev run` 需要 Bash、curl、flock、ss；`verify` 还需要 Node.js 18+（内置 `node:test`）和 Python 3。没有新增前端包管理器或生产 Node 运行时。
- 四个 Java 模块：`publisher-domain` 领域；`publisher-application` 用例；`publisher-infrastructure` 持久化与外部适配；`publisher-web` HTTP、模板和启动。
- 页面位于 `publisher-web/src/main/resources/templates/`；原生 CSS/JS 位于 `static/assets/`。文章草稿保存独立为 `draft-autosave.js`。
- 数据迁移位于 `publisher-web/src/main/resources/db/migration/`，不得修改已执行迁移。

## 可重复启动

在项目根目录执行：

```bash
./scripts/dev doctor
./scripts/dev run
```

`run` 已包含启动开发数据库，不需要再手工拼接 `dev-up`。入口检查 Java、工具、地址与端口；未指定 `DB_URL` 时启动并等待 Compose PostgreSQL；随后构建可执行 JAR，启动应用并等待 readiness。日志输出到当前终端，不自动后台驻留。

默认绑定 `127.0.0.1:8080`，`DISABLED` 只允许回环地址。指定 `DB_URL` 时必须同时提供 `DB_USERNAME`、`DB_PASSWORD`，此时不调用 Docker。变量由环境注入，不自动读取或打印 `.env`。密钥不放入命令示例或仓库。

同一项目、同一端口重复执行：原进程已健康则返回成功，不重复启动；正在启动或未健康则明确失败。被其他进程占用的端口直接失败，不杀进程。改变代码或配置后需先停止旧进程，再重新运行，重复调用不等于热重启。

```bash
# 仅在确认开发库内待执行任务安全后启用；可能触发外部 AI/Git/发布请求
PUBLISHER_JOBS_WORKER_ENABLED=true ./scripts/dev run
```

默认 Worker 仍关闭，防止审查或调试意外执行积压发布。首页和任务页显示暂停状态与启用方式。直接运行 JAR 的应用配置默认 Worker 为开启，与开发脚本有区别。

停止：原终端 `Ctrl+C`，脚本向本次启动的应用发送 TERM 并等待退出；数据库卷不删除。只停止开发数据库可执行 `./scripts/dev dev-down`。不要用 `dev-reset` 清理日常问题，它会删除开发数据库卷。

健康检查：

```bash
curl --fail http://127.0.0.1:8080/actuator/health/readiness
```

启动等待循环最多 60 次，每次健康请求最长 2 秒、间隔 1 秒；不就绪或进程提前退出时返回非零并停止本次应用。数据库不可用和迁移失败不会被吞掉。启动脚本的锁文件位于忽略目录 `target/`，运行时不要执行 `clean`，以免删除活动锁文件。

## 测试与构建

```bash
./scripts/dev verify
node --test publisher-web/src/test/js/*.test.cjs
python3 scripts/test-dev.py
./scripts/openapi check
./mvnw -DskipTests package
```

- `verify` 依次运行 JS 草稿状态测试、Python 启动入口合同测试、Maven `clean verify`（JUnit、MockMvc、JaCoCo、SBOM）。
- Python 测试在临时目录复制启动入口，以模拟构建器和本地 HTTP 进程验证正常启动、健康、重复调用、配置/依赖缺失、端口冲突、构建/进程失败和终止清理；**不能替代真实 PostgreSQL/Compose 验证**。
- JS 测试不连接网络，覆盖串行请求、旧响应、失败备份、会话过期、冲突、正式提交等待、本机存储不可用、无效字段与网络恢复。
- `PersonalWorkspaceIntegrationTest` 覆盖无认证开发入口、编辑可用性、监控入口保留与正式保存失败后的输入恢复。
- 同一测试还覆盖 55 篇文稿的覆盖矩阵搜索/分页、超过 50 篇新草稿不影响旧待发布文稿检索、`READY/APPROVED` 状态过滤、软删除与编辑控件合同。
- `AutomationApplicationServiceTest` 覆盖中英文 10 万字符边界、标签约束、已确认状态和版本冲突。
- JAR 产物位于 `publisher-web/target/content-publisher.jar`。`package -DskipTests` 不代表测试通过。
- Docker 不可用时真实 PostgreSQL 和恢复演练可能跳过；交付时必须单独说明。外部 AI、渠道真实发布需要专用测试账号，不在本地回归中自动调用。

## 浏览器检查

在隔离数据库启动应用后，检查：首页 → 写新稿 → 编辑 → 自动保存 → 保存并准备发布 → 发布工作区。另查 `/jobs`、`/monitoring`、`/channels` 和 `/actions`，以及内容库无结果筛选、深浅主题、移动导航。

建议检查 1440px 桌面与 320/375/414/768px 窄屏，记录页面标题、HTTP 状态、控制台异常、布局越界、键盘焦点和交互结果。截图仅作证据；未回读截图不能声称视觉验收通过。

### 可重复的工作区浏览器回归

新增 `scripts/test-workspace.cjs`，使用已有 Playwright 与 Chromium，不安装或锁定新的项目生产依赖。先通过 `scripts/dev run` 使用独立开发/测试 PostgreSQL 库启动应用，保持 `DISABLED`、回环监听、Worker/AI/渠道巡检/Webhook 关闭；**不要使用日常业务库**。脚本会创建文稿并确认版本，不会提交外部发布。

在另一终端执行：

```bash
# PLAYWRIGHT_MODULE 可为已安装模块的绝对路径；Chromium 路径可按已有环境指定。
# 以下目录必须位于仓库外，并可由当前用户写入。
PUBLISHER_UI_TEST_ALLOW_WRITES=true \
PUBLISHER_UI_TEST_URL=http://127.0.0.1:18087 \
PLAYWRIGHT_MODULE=/path/to/playwright \
PLAYWRIGHT_CHROMIUM_EXECUTABLE=/path/to/chromium \
PUBLISHER_UI_TEST_OUTPUT=/path/to/writable/qa-output \
node scripts/test-workspace.cjs
```

`PUBLISHER_UI_TEST_URL` 是必填测试地址，脚本拒绝非回环主机；写入确认、可写输出目录与 Playwright 是前置条件。页面/流程断言失败时非零退出，浏览器在 `finally` 中关闭。重复执行创建带时间标识的新测试文稿，不覆盖已有内容；停止应用仍使用启动终端的 `Ctrl+C`。测试数据只在专用测试库内保留或通过回收站清理，不自动清库。

覆盖内容：新建离开提醒、隐藏必填字段展开、英文生成触发自动保存、取消替换、生成期间修改、乱序预览、明暗主题五档宽度与人工发布保存文案。AI 返回值为浏览器请求替身，因此通过不代表真实 AI 服务健康。截图与 `result.json` 写入指定输出目录，不进入 Git。

本轮实际浏览器执行使用独立 H2 内存库及已解析的 H2 测试依赖，未连接 PostgreSQL 或日常库；它不能替代 PostgreSQL 集成验证。当前主机 `/tmp` 不可写时，按下节配置可写缓存目录，不改变目录权限或测试阈值。

## 排障与回滚

- 页面显示任务暂停：检查 `PUBLISHER_JOBS_WORKER_ENABLED`，不是任务丢失。
- 自动保存冲突：保留或复制编辑内容，重新核对正式版本，不盲目重试发布或覆盖新版本。
- 会话失效：恢复登录后检查同标签页应急草稿。应急备份使用按账号隔离的 `sessionStorage`，不承诺跨标签页、设备或关闭浏览器后的恢复。
- 无法创建临时文件：为测试设置自己可写的 `TMPDIR`；Java 同时设置 `-Djava.io.tmpdir`。不要修改系统临时目录权限来绕过环境限制。
- Mockito 自附加失败：检查 JDK/临时目录与附加权限；可通过 `JAVA_TOOL_OPTIONS` 加载 Maven 已解析版本的 `byte-buddy-agent`，不要更换 MockMaker 或删测试掩盖问题。
- 本轮无数据库迁移，回滚限于恢复变更前源码并重新构建、启动；无需删除数据库。正式发布、备份与制品回滚见[运维文档](OPERATIONS.md)。
