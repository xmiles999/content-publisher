# 主题色板

维护者：修改前端主题的开发者。适用读者：开发者、界面验收者。
实现入口为 `publisher-web/src/main/resources/static/assets/app.css`，
交互设计见[技术设计](TECHNICAL_DEVELOPMENT.md#15-前端与页面设计)，运行方式见[开发文档](开发文档.md)。

## 设计与边界

2026-09-26 的深色优化使用轻微冷色的石墨灰区分页面、侧栏、工作区和悬停表面，
不再让大面积背景带绿色。绿色仅用于主要操作、链接、焦点及成功提示。
深色图表主序列用灰蓝，与成功序列的绿色区分；状态仍保留文字或形状提示。
浅色既有色板不变，不改变布局、业务接口、主题偏好键或部署配置。

原始灰阶 `--graphite-950/925/900/875/850/800` 依次为
`#181a1d / #1c1e22 / #22252a / #25292f / #292d33 / #30353c`。
组件使用下表语义令牌，不直接依赖原始灰阶。表中列出解析后的颜色。
现有状态、阴影等令牌保留直接赋值，避免为无复用需求的色阶添加别名。

## 状态与组件令牌

- 深色主按钮、危险按钮与 Webhook 次按钮禁用时使用
  `disabled-text: #a5afbc`、`disabled-bg: #2b3037`、`disabled-border: #48515e`、
  `disabled-opacity: 1`，不用整块半透明导致文字变暗。
  浅色沿用各按钮本身的颜色与 `.45` 不透明度；这些令牌仅在深色赋值，通过 CSS 回退保留浅色行为。
  这不是所有原生禁用控件的统一重绘。
- 焦点描边使用 `primary`；输入焦点阴影 `focus-shadow` 在浅色为
  `rgba(70,107,84,.14)`，深色为 `rgba(155,196,172,.18)`。
- 对话框遮罩 `dialog-backdrop` 浅色为 `rgba(29,39,31,.4)`，
  深色为 `rgba(10,12,16,.70)`。现有面板、登录区及内阴影仅表达层级，未新增发光或渐变。
- 内联监控图形直接消费 CSS 变量，切换时无需重建图表。
  外部 `logo.svg` 沿用固定颜色的明暗共用图形，不假定它会继承页面变量。

## 切换与浏览器主题色

`theme-init.js` 仍在 CSS 加载前解析 `content-publisher:theme`，避免主题闪白。
延迟执行的 `app.js` 在初始化、手动切换、系统配色变化和跨标签页偏好同步时，
从根元素的计算样式读取 `--bg`，创建或更新唯一的 `meta[name="theme-color"]`。
不在 JS 复制色板；若 CSS 未加载、变量为空则不写入，页面主题偏好处理继续执行。
浏览器是否显示该颜色由浏览器本身决定，本项目没有原生壳。

## 验证方法与限制

```sh
node --check publisher-web/src/main/resources/static/assets/app.js
node --test publisher-web/src/test/js/*.test.cjs
```

`theme.test.cjs` 校验两种主题的正文/按钮至少 4.5:1、焦点及输入边界至少 3:1；
新增深色中性表面和明度顺序、辅助/状态/禁用文字至少 4.5:1、
图表颜色与轨道至少 3:1 的回归。
使用真实主题脚本的隔离 DOM 测试覆盖三态循环、首屏偏好、系统变化、
跨标签页变化、存储不可用及 `theme-color` 更新。
这些是选定令牌组合与行为的回归，不等同于所有透明叠层、所有浏览器的完整可访问性审计。

浏览器验收需检查写稿、发布、渠道和监控页面在桌面与移动宽度下的主题、焦点、悬停和控制台，
并验证刷新保留偏好、系统切换及跨标签页同步。隔离环境不得连接日常数据库或外部发布渠道。
本次验证记录在[优化实施记录](优化实施记录.md)；截图与临时脚本保留在仓库外，不加入生产包。
